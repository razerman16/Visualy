# Contrat interne MVP Scenzly

Toutes les routes sont sous `/api/v1`. JSON sauf upload multipart. Réponse erreurs `{error: string}`. Les listes renvoient directement un tableau. Les entités créées ou modifiées sont renvoyées directement. Dates ISO UTC. Identifiants UUID. URLs média toujours relatives `/api/v1/media/:id/file`.

Auth admin par cookie HttpOnly SameSite strict, fetch credentials same-origin. Player par `Authorization: Bearer <token>` ; fichiers via `?token=` (nécessaire pour image/vidéo HTML). Les ports web proxient `/api/` vers API.

- `GET /health` => `{status:'ok'}` vérifie DB.
- `GET /auth/setup` => `{required:boolean}`. `POST /auth/setup {email,password,name}` crée seulement le premier superadmin, puis session. `POST /auth/login {email,password}` => user. `GET /auth/me` => user. `POST /auth/logout`.
- User `{id,email,name,role:'superadmin'|'admin'|'editor'|'viewer'}`. `GET/POST /users` et `PATCH /users/:id {role}` superadmin.
- `GET /dashboard` => `{screens:number,online:number,media:number,programs:number}`.
- `GET /media` => Media[]. `POST /media` multipart un fichier champ `file`. `DELETE /media/:id`. `GET /media/:id/file` streaming et Range. Media `{id,name,mime,size,url,checksum,createdAt}`. Formats image JPEG PNG WebP, vidéo MP4 WebM ; conversion PDF via worker documentée si disponible.
- `GET/POST /scenes`, `PUT /scenes/:id`, `DELETE /scenes/:id`. Scene `{id,name,width,height,background,elements:SceneElement[],createdAt?,updatedAt?}`. SceneElement `{id,type:'text'|'image'|'video'|'shape'|'clock'|'qr',x,y,width,height,text?,mediaId?,color?,background?,fontSize?,fontWeight?,opacity?,rotation?,zIndex?}` ; positions pixels sur toile logique. Scènes et leurs médias rendus même modèle côté admin/player. Pour QR texte = contenu.
- `GET/POST /programs`, `PUT /programs/:id`, `POST /programs/:id/publish`, `DELETE /programs/:id`. Program `{id,name,items:PlaylistItem[],publishedVersion?:number,createdAt?}`. PlaylistItem `{id,type:'media'|'scene',refId,duration:number}` (secondes). Publication capture scènes et médias en révision immuable. Modification brouillon ne change pas diffusion.
- `GET/POST /groups`, `DELETE /groups/:id`. Group `{id,name}`.
- `GET /screens`, `PATCH /screens/:id {name,groupId,orientation,fallbackProgramId}`, `DELETE /screens/:id` révoque jeton. Screen `{id,name,groupId:null|string,orientation:'landscape'|'portrait',fallbackProgramId:null|string,lastSeen:null|string,currentProgramId?:string,online?:boolean}`. `POST /screens/:id/commands {type:'refresh'|'clear-cache'|'maintenance'|'resume'}`.
- `POST /players/pair/request {deviceId}` => `{requestId,code,expiresAt}`. `GET /players/pair/status/:requestId?deviceId=...` => `{status:'pending'|'paired'|'expired',token?,screenId?}` (token délivré une fois). `POST /players/pair/confirm {code,name,groupId?}` => Screen, admin authentifié.
- `GET /players/me/manifest` => Manifest. `POST /players/me/heartbeat {programId?,revision?,error?}` => `{commands:Array<{id,type}>}`. `POST /players/me/events {events:[{type,programId?,itemId?,message?,at?}]}`.
- `GET/POST /schedules`, `PUT /schedules/:id`, `DELETE /schedules/:id`. Schedule `{id,name,programId,screenId:null|string,groupId:null|string,priority:number,kind:'weekly'|'dated'|'exception'|'urgent',startDate:'YYYY-MM-DD',endDate:'YYYY-MM-DD',startTime:'HH:mm',endTime:'HH:mm',days:number[],exclusions:string[],timezone:'Europe/Paris'}` ; jours ISO lundi 1 dimanche 7 ; exactement une cible écran/groupe ; 00:00 à 00:00 = journée entière. Dates inclusives, plage horaire fin exclusive ; créneau traversant minuit rattaché jour de départ. Les conflits même cible + priorité + nature sont refusés si chevauchement connu. `GET /events` => événements récents.

Manifest `{revision:string,serverTime:string,screen:{id,name,orientation},fallbackProgramId:string|null,programs:PublishedProgram[],schedules:Schedule[],media:Media[]}`. PublishedProgram `{id,name,version:number,items:PlaylistItem[],scenes:Scene[],media:Media[]}`. Tous les fichiers du manifeste sont autorisés pour cet écran ; accès au catalogue interdit. Fallback intégré dans player si aucun programme. API peut déduire fallback du premier programme publié seulement si explicitement affecté ; aucun fallback automatique global.

Module partagé `@scenzly/shared` exporte types et `selectProgram(schedules:Schedule[], now:Date, fallbackProgramId:string|null):string|null`, `isScheduleActive(schedule, now)`, `schedulesConflict(a,b)`. Résolution urgence > exception > dated > weekly, puis priorité numérique, puis id pour stabilité. Le player reçoit uniquement ses campagnes filtrées. Tests DST/overnight/exclusions requis.
